# PhotocardMaker_web

포토카드 메이커의 GitHub Pages용 웹 버전입니다.

## 특징

- 누끼 기능 없음: 원본 사진을 카드 비율에 맞춰 바로 크롭
- 리본 템플릿 650 × 1004 PNG 생성
- 요소 컬러 / 텍스트 컬러 변경
- 이름, 자간, 폰트 크기, X 위치, 그림자, 테두리 조정
- 미리보기에서 드래그로 위치 이동 / 휠로 확대
- 얼굴 가이드 / 중앙 가이드
- 저장 경로 지정 및 브라우저에 폴더 핸들 기억 (지원 브라우저)
- Excel 일괄 생성 → ZIP 다운로드
- Excel 데이터 패널 정렬 / 필터 / 완료 상태 저장

## GitHub Pages 배포

1. 새 저장소에 이 폴더의 파일을 그대로 업로드합니다.
2. GitHub 저장소 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. `main` / `/ (root)`를 선택해 저장합니다.

## Excel 양식

`samples/포카_일괄생성_샘플.xlsx`를 사용합니다.

열 순서:

`템플릿 | 그룹 | 요소 컬러 | 텍스트 컬러 | 이름 | 이미지명 | 저장파일명`

현재 기본 템플릿은 `리본` (`RIBBON_V1`)입니다.
